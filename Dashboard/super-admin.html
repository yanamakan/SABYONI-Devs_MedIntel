Key Insights

  • Patient GrowthReal-time patient registrations tracked from Supabase PostgreSQL. Includes full profile management, preferences, session history, and document storage via Supabase Storage.
  • AI Engines — OCTAVIA & ARIAOCTAVIA (Sentinel) handles IoT device triage for clinical staff via Groq LLaMA. ARIA is the patient-facing health assistant — symptom analysis chatBot powered by Gemini 2.5 flash with Groq Fallback, with full chat history saved to ai_chat_history.
  • Appointments & RecordsLive count of all scheduled appointments across departments. Patients can self-book, cancel, request medical certificates, message doctors, upload documents, and request prescription refills — all routed through nurse_notifications.
  • Critical AlertsUnresolved critical patient alerts monitored in real time via OCTAVIA/Sentinel. Alert severity distribution tracked across low, medium, and critical thresholds in the sentinel_alerts table.
  • Google Maps & YouTube IntegrationPatient portal includes live clinic/pharmacy finder via Google Maps Places API (AdvancedMarkerElement). YouTube Data API v3 powers the wellness video tab — patients describe how they feel and receive curated health videos via /api/youtube.
